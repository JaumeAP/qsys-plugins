# Plugins per a Q-SYS

Repositori de plugins per a la plataforma Q-SYS (QSC).

> 🆕 **Començament de nou.** Aquest projecte s'ha reiniciat des de zero.
> Tota la feina antiga (que pot no funcionar amb les versions actuals de
> Q-SYS) s'ha desat, sense esborrar res, a la carpeta [`archive/`](./archive).
> Consulta-la sempre que vulguis recuperar codi o exemples anteriors.

## Estructura

- `archive/` — projecte antic conservat com a referència (només consulta).
- (aquí aniran els plugins nous a mesura que els vagis creant)

## Com començar

Encara no hi ha plugins nous. Quan en creïs un, afegeix-lo aquí i descriu-lo
en aquesta secció.
