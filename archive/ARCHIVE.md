# 📦 Arxiu — projecte antic

Aquesta carpeta conté la **versió antiga** del projecte de plugins de Q-SYS.

Es conserva com a **referència històrica**. Algunes coses poden no funcionar
amb les versions actuals de Q-SYS; per això el projecte s'ha reiniciat a
l'arrel del repositori.

## Què hi ha aquí

- **Plugins compilats**: `DolbyFader.qplug`, `Dolby Sweep V1.04.qplug`,
  `Dolby CPSeries Control V2.2.qplugx`, `MultiFlip-Flop.qplug`.
- **`Developer/`**: codi font en Lua (mòduls i plugins de desenvolupament),
  inclòs el submòdul `class` (jonstoler/class.lua).
- **`Dolby CP Emulator/`**: emuladors dels processadors CP650, CP750 i CP850.
- **`README.md`**: el README original del projecte.

> ℹ️ No cal esborrar res d'aquí. Si mai vols recuperar codi antic, copia'l
> des d'aquesta carpeta al teu projecte nou.
