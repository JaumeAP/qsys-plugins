# Recommended skills for all projects
#
# FORMAT: skill-name -> owner/repo
#
# INSTALL: Each skill can be installed with:
#   npx skills add owner/repo -s skill-name
# Or all from a repository:
#   npx skills add owner/repo
#
# Example installations:
#   npx skills add vercel-labs/skills -s find-skills
#   npx skills add obra/superpowers -s brainstorming
#   npx skills add anthropics/knowledge-work-plugins -s data-visualization
#
# Search available skills: npx skills find <query>
# Browse at: https://skills.sh/
#
# DO NOT remove an entry here just because a skill was uninstalled from a
# repo -- "uninstall X" means the local .claude/skills/X only. Only edit
# this file when told to explicitly (see config-export-import.md's
# standing rule, 2026-07-31), or when an entry is independently proven
# wrong (dead pointer, broken without a missing dependency).
