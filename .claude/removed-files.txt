# Files that were once part of this repo's .claude/ tooling and have
# since been deliberately removed here. One path per line, relative to
# .claude/ (comments start with #). On import (config-export-import.md
# step 2.2), any path in this list still present under the target
# repo's .claude/ gets deleted -- an older bundle may have installed it
# there before it was retired, and a plain blind-copy of the current
# bundle would otherwise leave that stale copy in place forever,
# orphaned and (for a hook) unregistered. If the deleted path is under
# hooks/, also remove its settings.json registration.
#
# hooks/local-merge-reminder.sh, hooks/sync-command-reminder.sh --
# removed 2026-07-26: both mechanized a "merge the working branch
# directly into the default branch, no pull request" policy that was
# deliberately left out of this repo's CLAUDE.md when the config bundle
# was first imported, to keep this repo's PR-based workflow. Leaving
# the hooks in place kept nudging the declined policy despite CLAUDE.md
# no longer stating it.
hooks/local-merge-reminder.sh
hooks/sync-command-reminder.sh

# skills/changelog-rules -- removed 2026-07-28, explicit user request.

# deleted from the bundle entirely, restored from git history and put
# back as optional -- see `.claude/skills-history.md` and
# config-export-import.md step 2.5 for the full timeline) before this
# final removal: changelog work now follows the repo-wide conventions
# stated directly where needed, not a dedicated skill.
skills/changelog-rules

# hooks/check-reply-format.sh, hooks/reply-format-preflight.sh --
# removed 2026-07-30, explicit user request. Same failure mode as the
# two hooks at the top of this list: they mechanically enforced reply
# rules (mandatory leading "Rebut:" line, Catalan-only, the
# bold/em-dash/ellipsis/header/table ban, numbered-lists-only) that were
# taken out of the common CLAUDE.md that same day, in favor of deferring
# to the `caveman` skill. A target repo that kept them would keep
# blocking replies over rules its own CLAUDE.md no longer states -- and
# merge-settings.sh preserves a target's existing hook registrations, so
# without this entry the stale registration would survive the import too.
# They stay on disk in the source repo, dead and unregistered, with their
# own retirement notes; this list is only about target repos.
hooks/check-reply-format.sh
hooks/reply-format-preflight.sh
